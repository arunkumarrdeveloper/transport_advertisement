# S.V. Arun Transport 🚛

S.V. Arun Transport is a responsive transport service website developed using HTML, CSS, and JavaScript.

The website provides information about the transport service, available vehicles, company details, and contact information through a clean and user-friendly interface.

## Features

- 🏠 Home Page
- 👤 About Us Page
- 🚛 Fleet / Vehicle Page
- 📞 Contact Page
- 📱 Mobile Responsive Design
- 🧭 Separate page navigation
- 📩 Contact form with message notification
- 🚚 Tata, Ashok Leyland and Eicher vehicle details
- 🎨 Modern and professional UI design

## Technologies Used

- HTML5
- CSS3
- JavaScript
